This view is the architecture model for Parts 1 and 2. Kubernetes schedules trainer pods onto worker nodes. Those pods talk to Redis for round coordination and to a shared volume for MNIST shards and checkpoints. The FedAvg job wakes from Redis and reads updates from the PVC.
